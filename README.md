# Virus community response and potential role in metabolic rewiring of methane-suppressed soils code base

This repository contains all the code used in "Virus community response and potential role in metabolic rewiring of methane-suppressed soils" [https://doi.org/10.1371/journal.pbio.3003925] (https://doi.org/10.1371/journal.pbio.3003925)

Refer to README.txt for a tab-delimited file of all figures, corresponding input data, code, output files, and notes that can be found at the permanent repository https://zenodo.org/records/21343190.
